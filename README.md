# Simple Silver Ore

A simple and lightweight silver generation mod for Minecraft

## About

Simple Silver Ore is a small, focused mod designed to introduce silver into Minecraft without unnecessary complexity.
The goal is to provide the essential silver resources needed by other mods and modpacks, keeping the experience simple and compatible with existing modded gameplay.
It's ridiculously simple, so you only need a few items: ore (normal and deepslate), raw ore, ingots, and a block.

it's for Minecraft 1.21.1 and NeoForge
